# Askir RPG V30

Baut vollständig auf V29 auf. Neu: mapbezogene Persistenz für platzierte Loot-Pickups und Truhen, Truhen-Questzielintegration.

**Unreal Editor:** Für jede platzierte Truhe und jedes persistente Pickup eine einzigartige `PersistentLootID` vergeben. In der Dorfmission die Truhe mit `QuestID` und `ObjectiveID` konfigurieren. Spawns ohne ID sind nicht persistent.

**Grenzen:** Kein kompiliertes Unreal-Build, keine fertigen `.umap`/`.uasset`-Level.
